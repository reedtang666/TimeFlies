# ⏱️ TimeFlies

> 记录陪伴宝贝长大的每一秒。一个精致、极简的成长时长计数器。
> 
> A minimal and heart-warming growth timer to celebrate every second of growing up.

![TimeFlies Banner](https://raw.githubusercontent.com/placeholder/timeflies-preview.png)

---

## ✨ 项目初衷

“XX 已经来到这个世界 **1460** 天 **12** 小时 **30** 分 **15** 秒……”

作为一个程序员，我想用代码记录下孩子在这个世界上每一个闪闪发光的瞬间。这个项目没有任何复杂的逻辑，只专注于做好一件事：**实时、精准、优美地展示成长历程**。

无论是记录**孩子的成长轨迹**、**陪伴宠物的天数**，还是**情侣相爱的美好时光**，`TimeFlies` 都能为你留住这份岁月的礼物。

---

## 🎨 功能特性

- ⏱️ **精准到秒**：实时平滑更新，见证生命的每一次跳动。
- 📱 **全端响应式**：完美适配 Mobile、Tablet 与 Desktop 界面。
- 🎨 **极简视觉设计**：支持优雅的动态数字翻牌/渐变效果，提供深色/浅色模式切换。
- 🔗 **零代码 URL 配置**：无需部署代码，通过 URL 参数即可快速生成专属页面。
- 🔒 **数据隐私保障**：纯前端计算与渲染，不收集、不上报任何个人或家庭敏感数据。

---
